# geospine — Àlááfìa geography spine

The canonical Nigerian administrative hierarchy that **everything else in the
Àlááfìa platform keys to**. National → state → LGA → ward (settlement next),
stable P-codes, name aliases, a fuzzy name resolver, a point-in-polygon
resolver, and source→canonical crosswalks.

This is Phase 0, step 1 of `../../ALAAFIA_VISION_2026-09-06.md`: *"getting 40
messy sources onto one Nigerian admin hierarchy and one time axis is weeks of
unglamorous work every buyer needs and none want to do."*

## Use

```bash
uv sync
uv run geospine fetch            # OCHA COD + GRID3 wards + health facilities
uv run geospine build            # -> geo_unit / geo_alias / geo_source_meta (+ geo.duckdb)
uv run geospine crosswalk dhs    # -> crosswalk_dhs.parquet
uv run geospine facilities       # -> geo_facility.parquet  (41,778, geocoded)
uv run geospine fetch --big      # + GRID3 settlement extents v3.1 (~736 MB)
uv run geospine settlements      # -> geo_settlement.parquet (level 4; git-ignored, large)
uv run pytest
```

```python
from geospine.resolve import NameResolver, PointResolver

NameResolver(level=1).resolve("Nassarawa")            # -> NG026  "Nasarawa"
NameResolver(level=1).resolve("FCT")                  # -> NG015  "Federal Capital Territory"
abia = NameResolver(level=1).resolve("Abia").pcode
NameResolver(level=2, parent_pcode=abia).resolve("Aba North")   # -> NG001001

PointResolver().locate(8.5264, 12.0022)              # -> {state: NG020, lga: NG020021, ward: NG020012001}
```

Or read the parquet directly (no package needed):

```python
import duckdb
duckdb.sql("SELECT * FROM 'data/spine/geo_unit.parquet' WHERE level=2 AND adm1_pcode='NG020'")
```

## Schema

`geo_unit` — one row per admin unit. Key columns: `pcode` (PK), `level`
(0–4), `name` / `name_official` / `name_key`, `parent_pcode`, `adm1_pcode` /
`adm2_pcode` (denormalised ancestors), `senatorial_pcode` / `senatorial_name`,
`area_sqkm`, `center_lon` / `center_lat`, `valid_from` / `valid_to`, `source` /
`source_version`. Full comment in `src/geospine/build.py`.

`geo_alias` — `pcode`, `alias`, `alias_key`, `alias_type`
(`official|ref_name|altname|manual`), `source`. The resolver matches against this.

`geo_source_meta` — provenance: one row per fetched file (url, licence,
provider, sha256, retrieved_at).

`crosswalk_dhs` — `dhs_scheme` (`sstate`|`v024`), `dhs_code`, `dhs_label`,
`pcode`, `canonical_name`, `match_score`, `match_method`, `verified`.

`geo_facility` — `facility_id`, `nhfr_code`, `name`, `alt_name`, `lon`/`lat`,
`level`, `type`, `ownership`, `ownership_type`, `functional`, `state_pcode` /
`lga_pcode` / `ward_pcode` (by name) + `*_pt` (by point) + `ward_agree`.

`geo_settlement` — `pcode` (`<parent>S<nnnnn>`), `parent_pcode`, `parent_level`
(3 ward / 2 lga / 1 state / 0 unplaced), `ward_pcode` / `lga_pcode` /
`state_pcode`, `type`, `bldg_count`, `bldg_area_m2`, `center_lon` / `center_lat`,
`source_id` (GRID3 MGRS code). **Build product — git-ignored** (21 MB points +
823 MB polygons), regenerated by `geospine settlements`.

## Known limitations

- **Ward + settlement P-codes are synthetic**, bound to `grid3_wards v3.0` /
  `grid3_settlements v3.1` (no released national standard for either). Deterministic
  order, not stable across GRID3 revisions.
- **Settlements have no names** (v3.1 extents are unnamed built-up areas keyed by
  MGRS code) and are placed by centroid point-in-polygon — dense urban wards where
  GRID3 merges everything into one Built-up Area get all of it assigned to the ward
  the centroid lands in (5,251 / 5,872 wards have ≥1 settlement).
- **No time dimension yet.** Every admin unit is `valid_from` 2019-04-17,
  `valid_to` null. Nigeria has created/renamed LGAs & wards; a boundary-change
  crosswalk is a follow-up.
- **DHS `sstate` numbering + `v024`→zone mapping are asserted** by the
  epicause_ng pipeline, not verified against the official NGIR8 recode manual.
  Crosswalk rows carry `verified = false`.
- Git-ignored, regenerated by the CLI: `geo.duckdb`, `geo_ward_geom.parquet`
  (~175 MB), `geo_settlement*.parquet`. Committed: the small canonical parquets +
  `geo_facility.parquet`.
